# my-first-repo

A simple Python calculator utility.

## Usage

```python
from calculator import add, subtract, multiply, divide

result = add(2, 3)      # 5
result = subtract(10, 4) # 6
result = multiply(3, 4)  # 12
result = divide(10, 2)   # 5.0
```

```bash
python -m pytest tests/
```
